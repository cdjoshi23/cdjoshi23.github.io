Selected work

Proven in production

Systems I designed and built, and what changed because of them. Client names are kept private.

API platform · AWS

Usage-based billing for a commercial API platform

Challenge: API customers could not be charged on usage, and hourly usage data was being lost.

What I did: Designed unique-container tracking and unified billing, aligned product and finance over 16 design versions, and fixed the Aurora capacity timeouts that dropped data.

Outcome: Usage-based charging shipped with daily and monthly roll-ups, CSV reports, customer emails and an in-portal usage view.

.NET 8, Lambda, Aurora, DynamoDB, Stripe

Event-driven · Security

Event subscriptions that are safe to launch

Challenge: Customers needed to subscribe to event types without ever receiving events they were not entitled to.

What I did: Designed a fail-closed entitlement gate and all-or-nothing routing across Oracle and DynamoDB, released behind feature toggles in a 4-step rollout.

Outcome: Subscriptions launched with entitlement enforced on every event.

EventBridge, SQS/SNS, DynamoDB, Oracle, feature toggles

Observability · Reliability

End-to-end visibility for a production API platform

Challenge: Faults across the gateway, containers and functions were found late, and webhook deliveries failed silently.

What I did: Led the Datadog rollout across Apigee, .NET ECS services and Lambdas. When the new monitors exposed a hidden webhook defect, traced it and redesigned delivery as accept-then-deliver.

Outcome: The team sees faults as they happen. 6 production incidents resolved with written root-cause analyses.

Datadog, Apigee, ECS, FireLens, Lambda

AI engineering

An AI-assisted SDLC for a delivery team

Challenge: Specs, backlogs and code reviews were slow and uneven across the team.

What I did: Wrote the team Claude Code standard (10 phase guides), connected it to Jira, Confluence, GitLab, Snowflake, Datadog and SmartBear through MCP, and built a spec-to-backlog pipeline.

Outcome: Requirements flow into Confluence designs and a Jira backlog from one specification.

Claude Code, MCP, BMAD, Jira, Confluence, GitLab

Machine learning · GenAI

Three AI use cases proven on AWS

Challenge: The team needed evidence of where ML and GenAI could add value in port logistics.

What I did: On my own initiative built container-ETA prediction with SageMaker XGBoost, an LLM code-review assistant for GitLab merge requests and a Bedrock, Rekognition and Textract demo platform.

Outcome: ETA prediction reached 70-95% accuracy in testing. All three were proposed for team adoption.

SageMaker, XGBoost, Bedrock, Rekognition, Textract, Python

IoT · Azure

IoT-enabled car park booking engine

Challenge: Legacy booking and asset systems could not talk to the sensors on site.

What I did: Replaced them with IoT-enabled, event-driven microservices on Azure, fully provisioned as code.

Outcome: One platform for bookings, assets and devices.

Azure Functions, Service Bus, Cosmos DB, API Management, Pulumi
